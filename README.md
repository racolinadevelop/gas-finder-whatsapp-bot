# Gas Finder WhatsApp Bot

A WhatsApp bot and REST API that helps users find nearby gas stations and compare fuel prices.

## Project Goal

The goal of this project is to allow users to share their location through WhatsApp and receive nearby gas stations with information such as:

- Gas station name
- Distance
- Fuel price
- Fuel type
- Cheapest option
- Closest option
- Best option based on price and distance

## Technologies

- Python
- FastAPI
- WhatsApp Cloud API
- REST API
- Git
- GitHub
